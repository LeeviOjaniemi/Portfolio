First models (2024)

While I had done some very basic 3D-modeling for art projects before, my first semester at XAMK also had me making my first proper 3D-models intended for game engine enviroments. All models were done using Blender with texture work being done in Microsoft paint.

The rolling hills, the great pines, the golden lakes

The first task was creating a simple low poly nature scene. I decided to create a scenee inspired by the beatiful nature of my homeland. The scene consists of few simple low-poly models of fir trees, some boulders and a low poly lake. Using some lights the end result ended up looking like a magnificent summer sunset in a lower definition world.

Triumph Herald

The second model I made was based on the Triumph Herald, a classic car from the 60s. (Wikipedia Article for Triumph Herald). I chose this specific car for it's complex yet elegantly simple shapes. Enough of a challenge, but still manageable to a beginner. The end result is satisfactory, but leaves something to be desired. This was later remedied in the "Driving Game", which includes a more refined red car as it's main character.
